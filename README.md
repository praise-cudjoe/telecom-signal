# Telecom Carrier Signal Simulator
A Python-based simulation of telecom carrier signals for understanding digital communication fundamentals.

## Overview
This project simulates square wave carrier signals and visualizes their time-domain characteristics - a core concept in telecom engineering, signal processing, and data transmission.

## Features
- Square wave carrier generation using NumPy
- Time-domain visualization with Matplotlib
- Configurable frequency and duration
- Clean, documented code for learning

## Tech Stack
Python, Numpy, Matplotlib
